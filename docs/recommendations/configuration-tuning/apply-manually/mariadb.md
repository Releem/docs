# Apply configuration manually for MariaDB

Manual application is unverified for MariaDB and is not currently documented. MySQL commands and configuration paths are not a substitute for a MariaDB procedure.

Review the [MariaDB required permissions](/supported-databases/mariadb/required-permissions) to understand the access boundaries. Contact Releem Support for the current application options and wait for a reviewed procedure before changing a production database.
