# Apply configuration manually for PostgreSQL

Manual application is unverified for PostgreSQL and is not currently documented. The absence of a procedure here does not establish whether the product supports a particular configuration change.

Review the [PostgreSQL required permissions](/supported-databases/postgresql/required-permissions) to understand the access boundaries. Contact Releem Support for the current application options and wait for a reviewed procedure before changing a production database.
