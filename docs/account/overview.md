# Account

Use Account documentation to manage access and billing separately from database monitoring and recommendations.

- Review account access in [Users and Roles](/account/access/users-and-roles).
- Manage billing details in [Payment Information](/account/billing/payment-information).
- Review the effects and steps in [Cancel Subscription](/account/billing/cancel-subscription).

## Open your server settings

Select **Settings** in the upper-right corner of the Releem Dashboard.
